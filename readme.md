1️⃣ What is the difference between var, let, and const?
    = var হলো function scope, re-declare এবং reassign করা যায়। let হলো block scope, re-declare করা যায় না কিন্তু reassign করা যায়। const হলো block scope, re-declare এবং reassign কোনটাই করা যায় না। যেসব variable এর value change হবে না সেগুলোতে const variable ব্যবহার করা হয়।

2️⃣ What is the spread operator (...)?
   = Spread operator (...) এমন একটি operator যা array বা object এর ভেতরের element গুলোকে ছড়িয়ে আলাদা করে দেয়। এটি ব্যবহার করে সহজে array copy করা, array merge করা, object copy করা এবং object update করা যায়।

3️⃣ What is the difference between map(), filter(), and forEach()?
   = map() method ব্যবহার করি  array এর প্রতিটি element এর উপর কাজ করে নতুন array তৈরি করার জন্য। filter() ব্যবহার করি condition অনুযায়ী element বেছে নিয়ে নতুন array তৈরি করার জন্য। আর forEach() ব্যবহার করি array এর প্রতিটি element এর উপর loop চালানোর জন্য, কিন্তু এটি নতুন array return করে না।

4️⃣ What is an arrow function?
   = Arrow Function হলো একটি ছোট syntax যেটা দিয়ে JavaScript-এ function লেখা যায়। => (arrow) চিহ্ন ব্যবহার করে লেখা হয়।

5️⃣ What are template literals?
   = Template Literals হলো JavaScript-এ string লেখার একটি সহজ উপায়। এটা backtick  ব্যবহার করে লেখা হয়, ${} দিয়ে variable বা expression বসানো যায়, এবং ব্যাকটিক দিয়ে একাধিক লাইনে string লেখা যায়।
